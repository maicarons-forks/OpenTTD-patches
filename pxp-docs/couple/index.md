# 列车对接

::: tip 注
列车对接与解挂功能原创于 [OpenTTD YPS 补丁](https://github.com/dylansan/OpenTTD-YPS/tree/Decouple)，px-patch 在此补丁的基础上，进行了新版移植与功能完善。
:::


对接操作允许两列列车合并一起运行，常与[解挂操作](/decouple/)共同使用。
