# 蓝图与撤回

::: tip 注
蓝图与撤回功能原创于 [OpenTTD Bluepoint 补丁](https://github.com/age77/openttd-15.3-blueprint)，px-patch 在此补丁的基础上，进行了功能完善。
:::


## 蓝图

蓝图功能允许你快速复制你的基础设施，例如车站等，而不用进行繁琐的重复性的建设


<DocFigure src="/images/bluepoint.png" alt="bluepoint" width="80" />


## 撤回

在撤回面板中，你可以撤回（删除）你最近进行的建设操作，以及查看最近的建造历史


<DocFigure src="/images/undo.png" alt="undo" width="80" />


_注：自定义机场的建设操作无法回退_
